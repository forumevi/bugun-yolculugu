# Bug'ın Yolculuğu

UnVault Türkiye topluluk etkinliği için hayran yapımı tarayıcı oyunu. Resmi bir UnVault ürünü değildir.

Kendi Genesis Bug'ını doğur, 8 zincirin kasaları arasında unvault et, partner mintleri yakala, telif korsanlarını DIVIT kalkanıyla durdur ve sonunda koleksiyon kartını indir.

Tek dosya (index.html), dış bağımlılık yok. Fare, klavye (1-8, P, M) ve dokunmatik desteği var.
